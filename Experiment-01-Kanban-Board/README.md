# Experiment 1 - Kanban Board using Trello

## Aim

To create a Kanban board using Trello and simulate a project workflow by moving tasks through To Do, In-Progress, and Done stages.

## Procedure

1. Opened Trello and created a new board named "Kanban Workflow Board".
2. Created three lists: To Do, In-Progress, and Done.
3. Added five task cards:
   - Collect project requirements
   - Design UI mockups
   - Develop login module
   - Test application
   - Prepare final report
4. Moved Collect project requirements and Design UI mockups to In-Progress.
5. Moved Collect project requirements to Done.
6. Moved Design UI mockups to Done and Develop login module to In-Progress.
7. Captured the final Kanban board as the output.

## Output

Final Kanban board:

- To Do:
  - Test application
  - Prepare final report
- In-Progress:
  - Develop login module
- Done:
  - Collect project requirements
  - Design UI mockups

## Result

Thus, a Kanban board was successfully created using Trello and the project tasks were moved through different stages to simulate the workflow.
